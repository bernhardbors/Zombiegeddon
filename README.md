# About Zoombiegeddon: 
Zoombiegeddon is a 2D-game where the player 
fights zombie animals across different levels to
stop an evil professor’s experiment.

# General info
 * Tilesets size 32x32



## Code Structure
* `inf112.zoombiegeddon` – code you can use as a starting point (rename to something sensible!)
	* `inf112.zoombiegeddon.app` – classes for launching the program
	* `inf112.zoombiegeddon.model` – model classes
	* `inf112.zoombiegeddon.view` – view classes
	* `inf112.zoombiegeddon.controller` – controller classes
